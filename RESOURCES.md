## 🆘 Common Issues & Solutions

### Issue: "Build Failed" on Railway
**Solution:**
1. Check Python version in Procfile
2. Verify requirements.txt has all packages
3. Ensure no syntax errors in bot.py
4. Check Railway build logs for specific error

### Issue: Bot doesn't respond
**Solution:**
1. Verify bot token is correct
2. Check Railway deployment status
3. View Railway logs for errors
4. Restart the deployment

### Issue: Can't push to GitHub
**Solution:**
1. Verify git config is set: `git config --list`
2. Check GitHub repository URL is correct
3. Try: `git remote -v` to see current remotes
4. If wrong remote: `git remote remove origin` then add correct one

### Issue: Environment variables not working
**Solution:**
1. Double-check spelling of variable names
2. No spaces around = sign in Railway
3. Restart deployment after adding variables
4. Check bot.py uses correct env variable names
